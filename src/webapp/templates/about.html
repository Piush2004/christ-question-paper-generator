About this project

Question Paper Intelligence is a constraint-first, curriculum-aware question-paper generator for CHRIST (Deemed to be University) BCA end-semester exams. It parses the real paper archive and syllabus, checks a teacher-supplied blueprint before calling any model, allocates questions with a CP-SAT constraint solver, generates and critiques candidates with a local LLM, and validates the finished draft deterministically before export.

It is teacher-assistance software: every paper it produces is a draft that a faculty member reviews and approves before use.

Author: Piush Kole, BCA, CHRIST (Deemed to be University). This is an independent student project — it is styled after the university's visual identity but is not an official university system, and is not affiliated with or endorsed by CHRIST (Deemed to be University).

See docs/VALIDITY_AUDIT.md and docs/EVALUATION_GENERATION.md in the project repository for the full, honest evaluation this app's Dataset & validity page is condensed from.
